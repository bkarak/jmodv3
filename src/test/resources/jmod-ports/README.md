# Vendored J% application ports

Subset of [bkarak/jmod-ports](https://github.com/bkarak/jmod-ports): only the `.jmod` sources used as compiler tests.

Application Java sources are omitted; the prototype compiles external types, not the original Swing/servlet programs.

Three benchmarking {@code CustomerSelect.jmod} files contain the original typo {@code imporg} and are asserted *not* to compile.
